# User stories

Format: *As a role, I want X, so that Y.* Acceptance criteria are checked by the tests named in `test-cases.md`.

1. **As an employee**, I want to see only my own tasks, so that I know what I have to do today.
   *Accepted when:* another person's tasks never appear in my list.
2. **As a manager**, I want to assign a task to a team member with a due date, so that ownership is clear.
   *Accepted when:* the task appears for the assignee and they get a notification.
3. **As an employee**, I want to mark a task started and then done, so that my manager can see progress.
   *Accepted when:* I cannot skip from todo to done, and completion time is recorded.
4. **As a manager**, I want to be told when a task I created is finished, so that I do not have to chase.
5. **As an employee**, I want to submit a leave, expense or purchase request, so that I do not need a chat thread.
6. **As a manager**, I want to approve or reject requests from my own team with a comment, so that the decision is on record.
7. **As a manager**, I want the system to stop me deciding my own request, so that approvals stay independent.
8. **As a manager**, I want to be unable to decide requests from other teams, so that responsibilities stay clear.
9. **As an admin**, I want large requests (above 1000) to need my approval, so that big spend is controlled.
10. **As an admin**, I want to create user accounts with a role, so that people only get the access they need.
11. **As an admin**, I want a log of logins and actions, so that I can answer "who did that and when".
12. **As a manager**, I want a summary of tasks by status, overdue tasks and average approval time, so that I can spot bottlenecks.
13. **As an employee**, I want to be told when my request is decided, so that I can plan.
